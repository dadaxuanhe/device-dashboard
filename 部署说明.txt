智能工厂设备监控看板系统 - 部署说明
==================================

一、环境要求
----------
- Node.js 14.0 或更高版本（推荐 18.x LTS）
- npm 包管理器（Node.js 自带）
- 现代浏览器（Chrome 90+ / Edge 90+ / Firefox 90+ / Safari 14+）
- 操作系统：Windows 10+ / macOS 12+ / Ubuntu 20.04+ 均可
- 无需安装数据库（SQLite3 为嵌入式数据库）
- 需要互联网连接（首次加载 ECharts 和 Font Awesome 的 CDN 资源）

二、安装步骤
----------
1. 安装 Node.js
   访问 https://nodejs.org/ 下载并安装 LTS 版本（推荐 18.x）
   安装完成后打开终端（命令行），验证安装：
     node --version    # 应显示 v18.x.x 或更高
     npm --version     # 应显示 9.x.x 或更高

2. 获取项目代码
   将 device-dashboard 文件夹复制到目标路径
   进入后端目录：
     cd device-dashboard/backend

3. 安装依赖
     npm install
   安装完成后，将自动创建 node_modules 文件夹，
   包含 express、sqlite3、cors 三个依赖包。

三、启动服务
----------
方式一：命令行启动（推荐）
  cd device-dashboard/backend
  npm start

  或直接：
  node server.js
服务启动后，控制台将显示：
  ==================================================
  智能工厂设备监控看板系统
  访问地址: http://localhost:3000
  静态文件: .../frontend
  ==================================================

系统会自动完成：
  - ✅ 检查并创建 SQLite 数据库
  - ✅ 创建 12 张数据表
  - ✅ 插入 480 条模拟数据（幂等，已存在则跳过）
  - ✅ 启动 Express 服务，托管前端静态文件

六、数据库说明
----------
数据库文件路径：device-dashboard/backend/data.db

系统首次启动时自动建表并插入模拟数据，共 12 张表：
  equipment, runtime, production, alarms, temperature,
  personnel, operations, maintenance, users, staff,
  op_log, performance

插入 480 条模拟数据：
  12 台设备 + 8 名人员 + 50 条告警 + 90 条产量记录
  + 200 条温度数据 + 60 条操作日志 + 30 条维修记录
  + 3 个用户 + 8 名值班人员 + 12 条操作记录 + 5 条绩效数据

七、初始化精确设备数据（可选）
----------
系统默认使用随机模拟数据。如需替换为精确的设备数据集
（12 台包含完整型号、制造商信息的真实设备参数），请执行：

  cd device-dashboard/backend
  node migrate-equipment.js

该脚本会清空旧数据并插入精确设备记录。

如需完全重置所有数据，删除 data.db 文件后重启服务即可。

八、默认端口
----------
服务默认监听 3000 端口，如需修改：

  Windows PowerShell:
    $env:PORT=3001
    node server.js

  macOS / Linux:
    PORT=3001 node server.js

九、常见问题
----------
Q1：启动报错 "Cannot find module 'express'"
A1：请先在 backend 目录下执行 npm install

Q2：端口 3000 被占用
A2：按上述方法修改端口号，或使用：
     npx kill-port 3000

Q3：页面空白或样式错乱
A3：确认浏览器可访问 CDN 资源（cdn.jsdelivr.net / cdnjs.cloudflare.com）
    首次加载需网络下载 ECharts 和 Font Awesome

Q4：数据库异常
A4：删除 data.db 文件后重启服务即可重新初始化

Q5：登录后页面空白
A5：确认已正确访问 http://localhost:3000/login.html
    使用默认账号 admin / 123456 登录

Q6：图表不显示
A6：确认网络可访问 cdn.jsdelivr.net，ECharts 通过 CDN 加载
    如果内网环境，可下载 ECharts 到本地 assets 目录

Q7：侧边栏图标不显示
A7：确认 SVG 图标文件存在于 frontend/assets/icons/ 目录
    （共 10 个：alarm, collapse, dashboard, device, expand,
     logo, refresh, search, settings, user）

Q8：设置页面无法保存
A8：设置使用 localStorage 存储，请确认浏览器未禁用
